# A7-06 — DI и монтаж маршрутов (composition root) + ExportHandler

## Что сделано (ветка ai/task/A7-06)

1. **cmd/server/main.go — полная DI-композиция** (TODO(BEL-03..06) и undefined `authMiddleware` удалены):
   - `pgxpool.New(ctx, cfg.DatabaseURL)`;
   - миграции golang-migrate (`file://db/migrations` → postgres) — до старта HTTP;
   - 5 репозиториев: `PGUserRepo`, `PGRefreshTokenRepo`, `PGTripRepo`, `PGStopRepo`, `PGPhotoRepo`;
   - `s3.Client` (aws-sdk-go-v2, endpoint `S3_ENDPOINT`, static creds) → `storage.NewS3Storage` → `service.StoragePort`;
   - `jwtutil.NewHS256(cfg.JWTSecret, cfg.JWTAccessTTL, cfg.JWTRefreshTTL)`;
   - сервисы: `NewAuthService`, `NewTripService`, `NewStopService`, `NewPhotoService`;
   - хендлеры: `NewAuthHandler`, `NewTripHandler`, `NewStopHandler`, `NewPhotoHandler`, `NewExportHandler`.
2. **Auth**: `r.With(middleware.Auth(cfg.JWTSecret))` (обёртка http.HandlerFunc для chi `.Group`) на защищённые маршруты; публичные `/auth/*` и `GET /healthz` без auth.
3. **Все маршруты смонтированы** внутри `/api/v1`: trips CRUD, stops CRUD, photos CRUD + `POST /trips/{id}/photos/presign`, `GET /trips/{id}/export` — под auth (через `*.Mount(r)` каждого хендлера).
4. **ExportHandler** (`internal/api/handlers/export.go`): CSV header `order,title,description,lat,lng,visit_date`, разделитель `,`, `Content-Disposition: attachment; filename="<slugified title>.csv"` (пустой title → `trip.csv`), visit_date RFC3339, координаты 6 знаков, CSV-экранирование, 404/500 через `middleware.WriteError`. Unit-тесты: `internal/api/handlers/export_test.go` (6 тестов).
