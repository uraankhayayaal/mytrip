# Тестовый отчет по задаче FEL-02

## Общее описание
Реализованы страницы аутентификации Login и Register согласно требованиям задачи.

## Файлы реализованы:
- frontend/src/pages/Login.tsx
- frontend/src/pages/Register.tsx
- frontend/src/lib/schemas.ts (уже существовал)

## Реализация

### Login.tsx
- Использует react-hook-form с zodResolver для валидации
- Поля: email (type=email), password (type=password)
- При успешном логине устанавливает токен и перенаправляет на главную страницу
- Обрабатывает ошибки: 'unauthorized' и 'validation'
- Ссылка на регистрацию

### Register.tsx
- Использует react-hook-form с zodResolver для валидации
- Поля: name, email, password
- При успешной регистрации перенаправляет на страницу логина
- Обрабатывает ошибки: 'conflict' и 'validation'
- Ссылка на вход
